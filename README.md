#  Анализ маршрутов и аэропортов на основе данных OpenFlights

Этот проект представляет собой всесторонний анализ мировых авиаперевозок, основанный на открытых данных OpenFlights. Основной фокус — изучение активности аэропортов, рейсов и авиакомпаний, а также их географического охвата и структуры маршрутов

## Содержание проекта

-  **Анализ трафика аэропортов**: количество вылетов, прилётов, суммарная активность
-  **Визуализация на карте**: интерактивное отображение аэропортов по континентам
-  **Анализ авиакомпаний**:
  - количество рейсов
  - число уникальных стран
  - ширина маршрутной сети
